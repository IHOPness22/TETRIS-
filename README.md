# Tetris Clone

## Overview
I created a Tetris-style game in GameMaker using GML. I built the core systems entirely from my understanding of ds_grid, 
which made Tetris a perfect fit for practicing grid-based logic.

Using ds_grid, I was able to manage block placement, collision detection, line clearing, and the game board. 
I also created a rotation system using array-based block positions that are translated onto the grid. 
The game includes increasing fall speed as the game progresses.

## Features
- Grid-based board using ds_grid
- Piece rotation system
- Line clearing
- Increasing difficulty over time
- Collision detection
- Score tracking (if implemented)

## Controls
- A — Move Left
- D — Move Right
- S — Soft Drop
- Space — Rotate

## What I Learned
- Working with ds_grid data structures
- Managing grid-based game logic
- Implementing rotation systems
- Translating array positions into game-world positions
- Structuring larger GameMaker projects
